# Repository

Nama Lengkap: Irva Zahra Salasabilah Putri

## Deskripsi Repository
Repository ini merupakan tempat penyimpanan dan dokumentasi seluruh kegiatan, materi, dan catatan pembelajaran selama mengikuti kegiatan workshop secara daring.

## Tujuan Repository
Tujuan repository ini adalah untuk melatih penggunaan GitHub sebagai media penyimpanan dengan visibilitas Public, serta membiasakan penyusunan catatan dan pengelolaan file kegiatan workshop secara rapi dan terstruktur.

## Informasi Kegiatan Workshop
Repository ini mendokumentasikan kegiatan workshop untuk Day-1. Dokumentasi mencakup materi atau topik yang disampaikan pemateri, rangkuman catatan pembelajaran, serta poin-poin penting terkait pengetahuan baru yang berhasil dipelajari pada sesi workshop ini.
